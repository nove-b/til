自分の環境で実行したlintでは通るのに、GitHub Actionsのlintでは通らない事象が発生した。

原因は、**Prettierのバージョンのずれ**だった。

`package.json` では以下のように指定していた。

```json
"prettier": "^3.6.2"
```

`^` を付けていたため、インストールするタイミングによって異なる3.x系のバージョンが入る状態になっていた。

自分の環境で依存パッケージを最新化した際、`package-lock.json` にも変更が入っていたが、他に意図した変更がなかったため、その変更を破棄してしまった。

その結果、

* ローカルの `node_modules` には新しいバージョンのPrettier
* Git管理されている `package-lock.json` には以前のバージョンのPrettier

というずれが発生した。

そのため、自分の環境でlintを実行した場合と、GitHub Actionsで `package-lock.json` をもとに依存パッケージをインストールしてlintを実行した場合とで、Prettierのバージョンが異なり、lint結果にも差が出ていた。
